## 📖 About

Seed Validator cross-checks a known or cracked seed against in-game observable features — biome borders, structure positions, and slime chunks — to confirm the seed is correct.

---

## ✨ Features
<a name="features"></a>

- **Feature Cross-Check** — validates seed against 5+ observable features.
- **Confidence Score** — percentage certainty display.
- **Mismatch Alert** — flags any feature that does not match predictions.
- **Auto Biome Sample** — silently samples biomes as you walk.
- **HUD Status** — shows validation progress in real time.
- **Export** — save validation report to text file.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
